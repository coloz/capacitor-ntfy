# capacitor-ntfy

Capacitor Android foreground-service client for self-hosted ntfy servers

## Install

To use npm

```bash
npm install capacitor-ntfy
````

To use yarn

```bash
yarn add capacitor-ntfy
```

Sync native files

```bash
npx cap sync
```
